# Focus Lock

This extension can be downloaded on to a mac(still working on windows). If you click allow for it to access your chrome, it helps you focus when you need to sit down and get things done.
Select the apps and website links that you want to block and set the time duration
    During that duration of time, You will have no way to open them or unlock it unless you deinstall the app. 
It is still in the testing phase, so please email adithshakalya@gmail.com, if you have any suggestions or concerns.
